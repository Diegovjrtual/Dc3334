# 0low Connect V4.1 — servidores + call

## Render
Build Command: `npm install`
Start Command: `npm start`
Tipo: Web Service

## O que tem
- Criar servidor
- Lista de servidores online
- Entrar por código ou convite
- Chat #geral
- Membros
- Call geral
- Câmera e microfone
- Vídeo entre usuários por WebRTC
- Botão de compartilhamento de tela (quando o navegador oferece getDisplayMedia)

## Importante
Câmera/microfone precisam de HTTPS. O Render fornece HTTPS.
Compartilhamento de tela em celular depende do navegador e do sistema; se aparecer "não suportado", use um navegador que ofereça `getDisplayMedia` ou um app nativo.
